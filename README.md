# anajak-car

ฐานข้อมูลรถยนต์ไทย — รวมข้อมูลรถ (แบรนด์ / รุ่น / เจเนอเรชัน / รุ่นย่อย / สเปก / ราคา) ไว้ที่เดียว
สำหรับคนที่อยากเช็กข้อมูลรถให้แน่ใจก่อนตัดสินใจซื้อ

เป็น **ฐานข้อมูล** ไม่ใช่เว็บรีวิวรถ และไม่ใช่เว็บประกาศขายรถ
